# S10 令牌生命周期管理

> 状态：部分完成

## 1. 场景描述

管理接入网关所需凭据的全生命周期：创建（按 owner/过期时间）、查看、吊销、
轮换；吊销即时生效；过期自动失效。适用于内部服务令牌与 API Key 类凭据。

## 2. 现状分析

### 已完成（后端）

- tokens 表（app_id / value / owner / expires_at）与管理 API：
  `GET/POST /admin/api/apps/{id}/tokens`、删除接口（AdminApi 保留）。
- auth 规则 type=token 校验 Authorization Bearer，快照缓存 + 写时失效，吊销
  立即生效（[Auth.php](../../processor/src/Auth.php:42)）。

### 未完成 / 缺口

- 管理端 SPA 的令牌页已移除（产品决策），现只能走 REST/CLI。
- 无"轮换"（同一 owner 换新值并保留旧值宽限期）与批量导入。
- API Key（X-Api-Key）目前没有存储/校验体系（见 S07）。

## 3. 设置方法

后台接口：

```bash
# 创建（owner 建议填写；expires_at 不填即永久有效）
curl -s -X POST http://host/admin/api/apps/{appId}/tokens \
  -H 'Content-Type: application/json' \
  -d '{"value":"svc-a-0001","owner":"svc-a","expires_at":"2027-01-01 00:00:00"}'

# 列表 / 删除（吊销）
curl -s http://host/admin/api/apps/{appId}/tokens
curl -s -X DELETE http://host/admin/api/apps/{appId}/tokens/{id}
```

配合 S07 的 auth type=token 规则使用。

## 4. 测试方法

1. 创建令牌 → 带 Bearer 请求被放行；错误/不存在令牌 401。
2. 设置过期时间并等待过期（或把时间改到过去）→ 401。
3. 删除令牌后同一令牌立即 401（无需等缓存 TTL）。
4. 自动化：adminapi_test / jwt_test 中 token 相关断言；可在 e2e 增加"吊销后
   401"用例。
