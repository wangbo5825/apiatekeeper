# S07 统一认证前置（JWT/内部令牌）

> 状态：部分完成

## 1. 场景描述

网关作为统一入口做认证前置：JWT（HS256/RS256）或内部不透明令牌校验通过后才
转发上游；认证失败 401。调用方身份（JWT sub / X-Api-Key / IP）被归一后用于
规则匹配与统计。

## 2. 现状分析

### 已完成

- auth 规则类型：jwt（secret / public_key，issuer/audience 参数存在但当前校验
  在 Jwt 解码层）与 token（应用内 tokens 表，含过期，APCu 快照）
  （[Auth.php](../../processor/src/Auth.php)、[Jwt.php](../../processor/src/Jwt.php)）。
- 失败返回 401 + `WWW-Authenticate: Bearer realm="gatekeeper"`。
- 身份归一：JWT subject > X-Api-Key > IP（[Identity.php](../../processor/src/Identity.php)），
  规则可按 `user:` / `key:` / `ip:` 匹配（见 S08）。
- 管理 UI：应用详情 → 规则 → auth 表单（类型 jwt / token、密钥、issuer、
  audience）。

### 未完成 / 缺口

- API Key 只作为"身份标识"，**没有独立的 API Key 校验**（token 认证只认
  Authorization 头的 Bearer 令牌）。
- 管理端令牌页已移除；发放/轮换/吊销走后台接口或 CLI（见 S10）。
- 无 scope/claim 级授权（见 S08）。
- 规则参数 issuer / audience 目前只保存不参与校验：Jwt 解码仅按 config 的
  auth.default_issuer / auth.default_audience 校验（[Jwt.php](../../processor/src/Jwt.php:42)）。

## 3. 设置方法

管理 UI：应用详情 → 规则 → auth。

等价 REST：

```bash
# JWT（HS256；密钥可放规则或 config.php auth.jwt_secret）
curl -s -X POST http://host/admin/api/apps/{appId}/rules \
  -H 'Content-Type: application/json' \
  -d '{"name":"订单JWT","api_pattern":"GET /orders/*","client_pattern":"*",
       "action_type":"auth","phase":"access","scope":"app",
       "params":{"type":"jwt","secret":"change-me","issuer":"gatekeeper"}}'

# 内部不透明令牌（先建令牌）
curl -s -X POST http://host/admin/api/apps/{appId}/tokens \
  -H 'Content-Type: application/json' -d '{"value":"svc-token-1","owner":"billing"}'
curl -s -X POST http://host/admin/api/apps/{appId}/rules \
  -H 'Content-Type: application/json' \
  -d '{"name":"内部令牌","api_pattern":"*","client_pattern":"*",
       "action_type":"auth","phase":"access","scope":"app",
       "params":{"type":"token"}}'
```

调用：`Authorization: Bearer <jwt|token>`。

## 4. 测试方法

### 自动化

```bash
php processor/tests/run.php
```

覆盖 jwt_test.php（HS256 解码/过期/篡改）与 contract_test.php（无 token 拒绝）。

### 手工 / E2E

1. `./test/e2e.sh`：auth 用例确认无 token 访问 `GET /api/auth/*` 返回 401。
2. 用有效 HS256 token（如 `processor/tests/helpers.php` 的 make_hs256_token）
   请求 → 200 并转发。
3. 过期/错密钥 token → 401；身份为 `user:<sub>` 的 client 记录出现在统计中。
