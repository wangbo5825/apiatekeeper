# S24 用量报表与数据导出

> 状态：部分完成

## 1. 场景描述

按 API / 客户端 / 时间段输出用量报表：总量、错误、拦截、平均延迟、趋势；
支持 CSV 等格式导出，供运营/对账/内部月报使用。

## 2. 现状分析

### 已完成

- 统计链路完整：api_stats（api×小时/天）、client_stats（client×小时/天）、
  request_logs（明细）。
- 管理端查询接口：apis（带总量与 avg_ms）、clients、stats（按小时桶）、
  dashboard 聚合。
- 管理 UI：仪表盘趋势表、应用概览、API 列表、客户端页。

### 未完成 / 缺口

- 无日期范围过滤与分组报表接口（如"某天每客户端每 API"）。
- 无 CSV/Excel 导出。
- Prometheus 无 api/client 标签（见 S02）。

## 3. 设置方法

当前用管理端接口取数：

```bash
# API 排行（含总量/平均延迟）
curl -s http://host/admin/api/apps/{appId}/apis

# 小时趋势
curl -s http://host/admin/api/apps/{appId}/stats

# 客户端排行
curl -s http://host/admin/api/apps/{appId}/clients
```

规划：新增 `GET /admin/api/reports/usage?from=&to=&group=api|client|api_client`
与 `Accept: text/csv` 导出。

## 4. 测试方法

1. 制造跨两小时的流量并运行导入/聚合。
2. 各接口返回与 request_logs 汇总一致（抽样对账）。
3. 规划验收：导出 CSV 表头与行数与查询接口一致；Excel/WPS 可打开。

  api_stats，但 request_logs 仍全量）。
