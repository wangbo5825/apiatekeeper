# ApiGateKeeper 场景案例目录

每个应用场景一个文件，集中放在本目录（`docs/scenarios/`）。

## 文件命名规则

`S<两位序号>-<场景名>-<状态>.md`

状态取值与含义：

| 状态 | 含义 |
| --- | --- |
| 已完成 | 场景所需功能已实现并有可操作配置/验证路径 |
| 部分完成 | 核心能力可用，但缺关键环节（管理面 / 某类参数 / 某阶段） |
| 未完成 | 尚无实现；文件中的"设置 / 测试"为规划方案，供排期参考 |

## 通用测试环境

- 单元测试：仓库根目录执行 `php processor/tests/run.php`（发现
  `processor/tests/*_test.php` 中的 `test_*` 函数）。
- 管理端 / 处理器接口本地验证：`php processor/dev-server.php 127.0.0.1 8081`，
  再 curl `/admin/api/*` 与 `/__proc/request`；首次使用先跑安装向导
  （`POST /admin/api/install`）。
- 端到端（真实转发 + Souin 缓存）：Linux/WSL 下
  `FRANKENPHP=./deploy/bin/frankenphp ./test/e2e.sh`（需先按
  `deploy/README.md` 构建含 caddy-access-filter 的 FRAMPP 二进制）。
- 管理端 Web：`http://<host>/admin/`，首次访问进入安装向导。
